# BioLuna – Shopify theme

BioLuna is a herbal wellness store for the Ozlex line (herbal tea, Turkish herbal coffee, firming body gel) and related care ranges, selling direct to consumers in Romania.

**Live store:** https://bioluna.ro

## Problem & concept

People who buy herbal tea or coffee online in Romania usually get a marketplace listing: one product, no guidance, no reason to come back. BioLuna is a direct-to-consumer store built around a daily routine. Each product page explains how the product fits into the day, and bundles group the products that are used together, so the customer buys a routine instead of a single box.

## Main features

- Product pages with benefit bullets, ingredients, usage steps, delivery estimate and a "from the same range" row
- Routine bundles and promo packs, with the saving calculated from the real component prices
- Cash-on-delivery order form (EasySell app embed) next to the standard add-to-cart flow
- Cart drawer with matched add-ons and a free-shipping progress bar
- Collection pages with sub-category chips and sorting
- Custom search results page
- Customer reviews (Judge.me)
- Meta Pixel, TikTok Pixel and Google Tag Manager for campaign tracking
- Email capture (newsletter form, theMarketer)
- WhatsApp chat button and click-to-call bar
- Seasonal campaign layer (Black Friday homepage, product and collection templates) that can be switched on and off with one store setting

## No-code stack

Shopify · Shopify theme editor · Shopify apps (EasySell, Judge.me) · theMarketer · Meta Business Suite · Canva · Higgsfield · Claude

## What is in this repository

Only the code written for BioLuna: the custom sections and snippets (`sections/bio-*`, `snippets/bio-*`) and the JSON templates that define each page. The store runs on the Hyper theme by FoxEcom, which is a paid theme; its own files are not published here because the licence does not allow redistribution.
